# CLI Installation

These commands should be run in terminal/powershell to install `ghqc`.

## Unix-Like Systems (Linux, macOS)
```bash
curl -sSL https://raw.githubusercontent.com/A2-ai/ghqctoolkit/refs/heads/main/scripts/install.sh | bash
ghqc --version
```
