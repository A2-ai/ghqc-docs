## CLI Installation

These commands should be run in terminal/powershell to install `ghqc`.

### Unix-Like Systems (Linux, macOS)
```bash
curl -sSL https://raw.githubusercontent.com/A2-ai/ghqctoolkit/refs/heads/main/scripts/install.sh | bash
ghqc --version
```

### Windows

For now, you can download the `x86_64-pc-windows-msvc` zip archive from the [GitHub releases page](https://github.com/A2-ai/ghqctoolkit/releases/)
and extract it to a directory of your choive. Then add the `ghqc` binary to your PATH.

```bash
$env:PATH += ";C:\path\to\ghqc"
.\ghqc.exe --version
```

## R package

`ghqc` also has a lightweight wrapper R package that installs and runs the `ghqc` CLI. 

**To install the R package:**

The `ghqc` R package will also install the CLI for unix-like systems using `ghqc::ghqc_install()`. 

For more information regarding the `ghqc` R package, continue to the [R package reference](../rpkg/ghqc).
